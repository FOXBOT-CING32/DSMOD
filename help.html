📖 DS-MOD★ 教程

📌 重要提示

▶

• 所有模组必须打包为 .zip 格式

• 点击「模组管理」→「导入ZIP」选择你的模组包

• 图片支持： .png / .jpg / .gif / .webp

• 音效支持： .mp3 / .wav / .ogg

• 武器脚本： .lua 格式

⚠️ 所有字段不用就填 null，不要留空字符串

🔜 武器音效功能：未来版本将会添加，当前模板已移除音效代码

📊 特效编码对照表

▶

击中特效（HIT_EFFECT）

0 = 无特效
1 = 炫彩击中（彩色粒子爆炸）
2 = 真实血液（红色血液粒子）

挥空特效（SWING_EFFECT）

0 = 无特效
1 = 炫彩挥空（彩色轨迹）
2 = 默认（橙色轨迹）

子弹类型（BULLET_TYPE）

- = 线形炫彩（彩色线形子弹）
· = 典型普通（普通圆形子弹）
? = 无子弹（不发射子弹）

拖尾类型（TRAIL_TYPE）

- = 线形拖尾（彩色线形拖尾）
· = 典型拖尾（普通拖尾）
? = 无拖尾（不显示拖尾）

枪口闪光（MUZZLE_EFFECT）

0 = 无闪光
1 = 默认闪光（橙色）
2 = 炫彩闪光（彩色）

🎨 自定义函数说明

▶

近战武器函数

OnSwing(player) → 挥刀时触发
OnHit(target) → 命中目标时触发
OnEquip(player) → 掏出武器时触发
OnRender(player) → 每帧渲染

远程武器函数

OnShoot(player) → 射击时触发
OnHit(target) → 子弹命中时触发
OnReload(player) → 换弹时触发
OnEquip(player) → 掏出武器时触发
CreateBullet(player, angle) → 自定义子弹
OnRender(player) → 每帧渲染

🖥️ PC端操作说明

▶
W A S D → 移动角色
鼠标左键 → 攻击（按住持续攻击）
Q → 打开/关闭菜单
X → 切换武器
R → 换弹（远程武器）
空格键 → 全屏模式
ESC → 返回主菜单

💡 鼠标位置决定攻击方向，按住左键持续攻击

💡 打开菜单时所有按键自动隐藏

🎵 音效规则

▶
"swing.ogg" → 使用模组包里的本地音效文件
null → 无音效（系统不播放）
http://... → 网络音效URL

💡 音效文件放在 ZIP 包根目录即可

📁 分类说明

▶
PROP → 物品类（无伤害）
CREATURE → 生物类（可造成伤害）
VEHICLE → 载具类
TEST → 测试类
WEAPON → 武器类（近战/远程）
OTHER → 特殊类（音乐等）
