2. 数据隐私

我们重视您的隐私。您的邮箱地址仅用于登录验证和账号恢复，不会向任何第三方出售或共享。您的账户数据（包括模组上传记录、评论等）将存储在 GitHub 仓库中，仅用于平台功能。

3. 内容规范

您上传的模组、评论及其他内容必须符合以下规范：不包含暴力、色情、仇恨言论或任何违反当地法律的内容。我们保留删除违规内容及封禁账户的权利。

6. 账号安全与防盗

防盗号警告：您的账号安全至关重要！

• 邮箱 + 密码 是您账号的唯一凭证，请勿泄露给任何人。

• 您的 账户名字 只是显示名称，不能用于登录，也无法盗取您的账号。

• 平台采用 DSMOD·ID Guard 三重防护：邮箱识别 + 名字识别 + 名字唯一性，即使有人使用您的名字，也无法获取您的模组或账号。

• 建议您设置 强密码（至少8位，包含字母和数字），并定期更换。

• 如发现账号异常，请立即联系平台管理员。

警告：任何试图盗用他人账号的行为将被永久封禁，并可能追究法律责任。

我们保留随时修改或终止服务的权利，但我们会提前通过平台公告通知您。重要变更将直接发送到您的注册邮箱。
